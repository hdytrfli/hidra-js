# Hidra App

A multi-page app built with hidra-js, handlebars, and tailwind css.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Project Structure

```
src/
├── assets/          # CSS and JS entry points
├── components/      # Handlebars components (auto-registered)
├── helpers/         # Handlebars helpers (auto-registered)
├── layouts/         # Layout templates
├── libs/            # Shared TypeScript utilities
├── pages/           # Page templates (.hbs files)
└── global.ts        # Global data loader
```
